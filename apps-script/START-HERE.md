# ابدأ من هنا — من الصفر إلى بوت يعمل ✅

> الملف البرمجي: **`tax-reminder-telegram.gs`** — تُنسخ كل محتوياته وتُلصق في محرر Apps Script.
> الدليل المفصّل مع الأخطاء الشائعة: **`README-ar.md`**.

## قبل البدء

- تحتاج **حساب Google يعمل** (Gmail). إن كان حسابك الحالي يطلب تحققاً عبر بريد Proton ولا تستطيع إتمامه،
  أنشئ حساب Gmail جديداً: `accounts.google.com/signup` (مجاني، ويحتاج رقم هاتف للتحقق).
- كل الأدوات مجانية: Google Sheets + Apps Script + Telegram Bot API.

## الخطوات — ضع ✓ بعد كل خطوة

### ☐ 1. أنشئ الجدول وضع الكود
1. افتح **sheets.new** ← سمِّ الملف: `تذكير الضرائب`.
2. من القائمة: **الإضافات ← Apps Script**.
3. امسح كل ما في المحرر (Ctrl+A ثم Delete)، ثم الصق ملف `tax-reminder-telegram.gs` كاملاً ← **Ctrl+S**.
4. من قائمة الدوال اختر **`setupSheet`** ← **تشغيل (Run)**.
5. في نافذة الصلاحيات: اختر حسابك ← **مراجعة الصلاحيات** ← **متقدم/Advanced** ←
   **الانتقال إلى … (غير آمن)** ← **السماح/Allow**.

**يجب أن ترى في السجل:** `🆕 أنشأت ورقة «المتابعة»` … `✅ الجدول جاهز`.
افتح الجدول: ورقتان جاهزتان (المتابعة / السنوية) وخانات اختيار.

> بدأت من محرر مستقل على script.google.com؟ استخدم **`createSpreadsheet`** بدل `setupSheet`.

### ☐ 2. أنشئ البوت وخُذ التوكن
تيليجرام ← ابحث **@BotFather** ← `/newbot` ← اسم البوت ← يوزرنيم ينتهي بـ `bot` ←
انسخ سطر التوكن: `1234567890:AAH-xxxxxxxx…`.

### ☐ 3. ضع التوكن في الخصائص
في Apps Script: ⚙️ **Project Settings** ← **Script Properties** ← **Add script property**:
`TELEGRAM_TOKEN` = التوكن ← Save.

### ☐ 4. انشر كتطبيق ويب
**Deploy ← New deployment** ← ⚙️ اختر **Web app** ←
**Execute as: Me** و **Who has access: Anyone** ← **Deploy** ← اقبل الصلاحيات ←
انسخ **Web app URL** (ينتهي بـ `/exec`).

### ☐ 5. اربط البوت بالرابط
من قائمة الدوال اختر **`setWebhook`** ← **تشغيل**.
**يجب أن ترى:** `{"ok":true,"result":true,…}` و«✅ تم ربط الويب هوك بنجاح».

### ☐ 6. اعرف رقم محادثتك وضعه في الخصائص
1. أرسل للبوت: `مرحبا`.
2. سيرد: `⛔ هذه المحادثة غير مصرّح لها… رقم هذه المحادثة هو: 123456789`.
3. أضف الخاصية `TELEGRAM_CHAT_ID` = الرقم.
4. أرسل للبوت: `مساعدة` ← يجب أن تظهر قائمة الأوامر.

### ☐ 7. اختبر
| الدالة / الأمر | النتيجة المتوقعة |
|---|---|
| `checkSetup` | كل السطور ✅ في السجل |
| `sendTestMessage` | رسالة اختبار في تيليجرام |
| `sendTestReminder` | رسالة مرقّمة `1) … 2) …` |
| أرسل `دفع 1` | ✅ تأكيد + علامة ✓ في الجدول |
| أرسل `ملخص` | عدد المدفوع وغير المدفوع |

### ☐ 8. (اختياري) بيانات تجريبية
`addSampleData` تضيف 4 صفوف وهمية في «المتابعة» و2 في «السنوية» — **احذفها قبل بياناتك الحقيقية**.

## قاعدتان لا تُنسيان

1. **بعد أي تعديل في الكود:** Deploy ← **Manage deployments** ← ✏️ ← Version: **New version** ← Deploy
   （نفس الرابط، ولا حاجة لتشغيل `setWebhook` من جديد）.
2. **بعد إضافة خاصية** (توكن، رقم محادثة…): لا حاجة لإعادة نشر — تعمل فوراً.

## إن تعطّل شيء

| الحالة | أول ما تفعله |
|---|---|
| البوت لا يرد | شغّل `getWebhookInfo` وتحقق من الرابط و`last_error_message` |
| لا تصل الرسائل | شغّل `checkSetup` (التوكن / رقم المحادثة / الورقتان) |
| نافذة صلاحيات لا تفتح | اسمح بالنوافذ المنبثقة لـ script.google.com، أو استخدم نافذة تصفح خاص |
| «لم أجد جدولاً» | شغّل `createSpreadsheet` أو أضف `SPREADSHEET_ID` |
| أي خطأ آخر | انسخ السطر الذي يبدأ بـ `❌` أو `⛔` من السجل وأرسله |

## أوامر البوت باختصار

| الأمر | مثال | النتيجة |
|---|---|---|
| تسجيل بالرقم من آخر تذكير | `دفع 1` أو `دفع 1 3 5` | يسجّل مدفوعاً |
| تسجيل بالتفصيل | `دفع 2 5 1` (وحدة/شقة/وصل) | يسجّل مدفوعاً |
| الضريبة السنوية | `سنوي 2` | يسجّل السنوية |
| المتأخرات | `متأخر` | قائمة + إجمالي |
| الملخص الشهري | `ملخص` | مدفوع / غير مدفوع |
| المساعدة | `مساعدة` | قائمة الأوامر |

> يقبل الأرقام العربية (١٢٣) و«دفعت / دفعه / ادفع».
