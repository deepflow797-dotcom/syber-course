## Environment limitation found during P0 (does not affect the baseline gates)

The sandbox has no outbound access to `cdn.playwright.dev`, `deb.debian.org` or `storage.googleapis.com`, and no
system Chrome exists. `npx playwright install chromium` therefore fails with `ECONNRESET`
(`reports/evidence/p0-playwright-install.txt`). To run the *unchanged* e2e suite I provisioned a Chromium that can be
downloaded from npm (`@sparticuz/chromium`, installed outside the repository in `/tmp`) plus its bundled AL2023 shared
libraries, and pointed Playwright's cache at it through symlinks under `~/.cache/ms-playwright`. **No repository file was
changed for this**; the baseline commit is the untouched source. This is sandbox plumbing only and must be reproduced by
CI (GitHub runners download browsers normally).
